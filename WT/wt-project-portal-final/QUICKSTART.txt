🚀 QUICKEST WAY TO RUN (NixOS):
═══════════════════════════════════════════════════════════════════════

1. Start MySQL and import database:
   $ sudo systemctl start mysql
   $ mysql -u connectBase -pconnectBase wt_portal < database-schema.sql
   
   (If user doesn't exist, create it first - see SETUP.md)

2. Start the application:
   $ npm start

3. Open browser:
   → http://localhost:3000

🆕 HOW TO ADD NEW USERS:
═══════════════════════════════════════════════════════════════════════

Method 1 - Via API (when server is running):
$ curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"John Doe","email":"john@example.com","password":"pass123","role":"student"}'

Method 2 - Via Database:
# First, generate password hash:
$ node -e "require('bcrypt').hash('mypassword',10).then(console.log)"

# Then insert:
$ mysql -u connectBase -pconnectBase wt_portal
mysql> INSERT INTO users (name, email, password, role) 
       VALUES ('Name', 'email@example.com', 'HASH_HERE', 'student');
